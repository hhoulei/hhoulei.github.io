# Lei Hou Academic Website

## Preview locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a repository named `hhoulei.github.io`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages** and deploy from the `main` branch.
4. The website will be available at `https://hhoulei.github.io`.
